# Colony Wars

Experimental third-person game where you need to fight against an enemy colony that is dynamically expanding and becoming stronger.

You will progress from solo survival to a colony which you will lead into battle.

## Mechanics

- Procedural world generation & resource and object placement
- Inventory system
- Crafting, refining (workbenches, furnaces)
- Close quarters fighting system (Melee) with block & stun and stamina mechanics
- Squad system (Ordering, following, Commander units)
- Day & Night system
- Dynamic enemy colony expansion and attacks system

All graphics by [Badger](https://github.com/Badgerok) | [ArtStation](https://www.artstation.com/badgerzx)
